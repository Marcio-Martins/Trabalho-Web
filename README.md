# Trabalho Web — Projeto Integrador

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas da Universidade Santo Amaro (UNISA).

## Sobre o projeto

O repositório contém uma aplicação web de estudo com páginas em HTML, estilos CSS, JavaScript e scripts PHP. A estrutura inclui páginas relacionadas a agendamento, login, registro e conexão com banco de dados.

## Tecnologias identificadas

- HTML
- CSS
- JavaScript
- PHP

## Estrutura do projeto

```text
Trabalho-Web/
├── README.md
└── web/
    ├── index.html
    ├── style.css
    ├── script.js
    ├── agendamento.php
    ├── conexao.php
    ├── login.php
    └── registro.php
```

## Como executar

Como o projeto utiliza PHP, abra-o em um ambiente local com suporte a PHP. Se a funcionalidade de conexão depender de um banco de dados, configure o ambiente e as credenciais localmente antes de testar.

Não publique senhas, tokens ou credenciais reais no repositório.

## Objetivo de aprendizagem

Este projeto faz parte da minha formação e serve como prática de desenvolvimento web e integração entre arquivos de front-end e PHP.
